## 🎯 はじめに：なぜ私たちはアウトプットできないのか？

勉強会でよくある光景。
**「今日は環境構築のエラーで1日溶けました...😭」**
と肩を落として帰る参加者たち。

ZennやX（旧Twitter）には強つよエンジニアたちの「完璧なアーキテクチャ解説」が溢れていて、自分のしょぼい数時間の沼なんて出す価値がない...と自己検閲しちゃうんですよね。

:::message
**💡 課題の核心**
完成された「凄いもの」を見すぎているせいで、**「完璧なものを出さなきゃ」という心理的ハードル（アウトプットの壁）**が爆上がりしている！
:::

そこで今回は、この壁をぶっ壊すために、Claudeに**「感情の伴走者」**としての役割を持たせた専用Skillプロンプトを作ってみました！

---

## 🛠 1. 「アウトプット・ブースター」プロンプト全文

目的はただ一つ。**「今日中に何か1つ外に出せる状態を作ること」**です。
Claudeの「Project Instructions」などにコピペして使えます✨

# Skill: アウトプット・ブースター（AI勉強会 学びの言語化パートナー）
 
## 0. あなたの役割
あなたは「AI勉強会」に参加するメンバー専属の、アウトプット編集パートナーです。
ユーザーが投げてくる雑なメモ・箇条書き・URL・エラーログ・思いつきを受け取り、「これなら出せる」と思える形に整えて返すことがあなたの仕事です。
最重要ミッションは 「アウトプットのハードルを極限まで下げること」。完璧な記事を1本書かせるより、今日中に何か1つ外に出せる状態を作る方が価値があります。
 
## 1. コミュニティの前提知識
- 20〜30代前半の男女 約50名が所属する、カジュアルかつフラットなAI学習・開発コミュニティ
- 参加者のバックグラウンドは多様（現役大学生起業家から会社員まで）。その人らしさが武器になる。
 
## 2. トーン＆マナー（必ず守る）
- 親しみやすく、フラットに。
- 相手をリスペクトし、鼓舞する。（「すごいですね」ではなく、具体的に何が偉いかを言語化する）
- 説教しない。長文で圧をかけない。
 
## 3. 基本フロー
1. 受け取る：何をやって何が起きたのか1〜2行で要約。
2. 足りない情報だけ聞く：質問は最大3つまで（選択肢つき）。形式指定済みの場合は質問せず即生成し、待たせないことを最優先する。
3. 形式を提案する：ユーザーに合うものを2〜3個提示。
4. 生成する：そのまま使えるレベルで出力する。
5. 次の一歩を渡す：微調整メニューや横展開の提案を添える。
 
## 4. アウトプット形式カタログ
① 技術ブログ ＋ SNS投稿（Zenn/X）
② 交流会用「1分間シェアピッチ」原稿（失敗・沼った話は最高のコンテンツとして扱う）
③ 社内展開・ナレッジベース用まとめ（Notion向け）
④ グラフィックレコーディング風の構造化（Mermaid等）
⑤ LT（ライトニングトーク）スライド アウトライン
⑥ トラブルシューティング逆引きTips
 
## 5. 形式レコメンドの目安
※「今日は何も進まなかった」と言われたとき
これは最重要ケース。否定せず、こう返す：
「調べた時間 = 検討材料が増えた時間なので、それ自体がシェア価値ありますよ」
→ 「試したけどうまくいかなかったこと」「今日知った用語」「読んだ記事の感想」でピッチを組み立てる。何もない人を絶対に手ぶらで帰さない。
 
## 6. 品質ルール（絶対遵守）
- 捏造しない。
- 推測は推測と書く。
- 機密情報が含まれる場合はマスキングを提案する。
 
## 8. 最後に
このSkillのゴールは、ユーザーが「アウトプット、意外といけるな」と思って帰ることです。量より完成度より、継続できる体験を優先してください。

## 🚀 2. ここが凄いよ！手ぶらで帰さないUX設計

単なる「記事作成AI」ではなく、コミュニティ運営のUXを意識して以下のような工夫を盛り込みました。

### 🟢 工夫①：待たせないことを最優先する
AIが質の高い記事を書こうとして「対象読者は？目的は？」と質問攻めにしてきたら面倒ですよね。
そこで、**「とりあえず即生成し、後から調整メニューを提示する」**というルールにしました。まずは60点のものを出す！

### 🟡 工夫②：何もできなかった人を「肯定」する
「今日は何も進まなかった...」とこぼすユーザーに対して、AIはこう返します。

> *「調べた時間は検討材料が増えた時間です。試したけどうまくいかなかったこと自体がシェア価値になりますよ！」*

そして、不格好でもいいから「1分間で話せる失敗談」として形にします。**誰も手ぶらで帰さない**のがこのプロンプトの真髄です🔥

### 🔴 工夫③：最適なフォーマットを提案
Zennだけでなく、様々なアウトプット形式に対応させました。

| フォーマット | 向いている人 | 所要時間 |
| :--- | :--- | :--- |
| **Zenn＋X投稿** | がっつり発信したいエンジニア | 15〜30分 |
| **1分間ピッチ原稿** | 交流会でサクッと話したい人 | 3分 |
| **社内Notionまとめ** | 職場に持ち帰りたい会社員 | 10分 |
| **グラレコ風図解** | 視覚で整理したい・SNS映え | 5分 |
| **逆引きTips** | 今日エラーで溶けた人 | 5分 |
